# homebrew-skeeper

Homebrew tap for [skeeper](https://github.com/dak-ia/skeeper) — minimal terminal session keeper.

[skeeper](https://github.com/dak-ia/skeeper)配布用のHomebrew tapです。

## Install

```sh
brew install dak-ia/skeeper/skeeper
```

Or tap explicitly / 明示的にtapする場合:

```sh
brew tap dak-ia/skeeper
brew install skeeper
```
